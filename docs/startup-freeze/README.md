## 用户提供的现象

用户在正常使用一段时间后重新打开 TiebaLite；互联网可正常使用，但首页的关注吧等项目持续显示灰色骨架占位，清除缓存无效；用户报告全部控件（包括页面按钮）无法点击。提供的截图显示首页标题、顶部工具栏、底部三个导航图标和两组灰色占位，但单张静态截图不能验证触控是否实际失灵，也不能判断等待了多久。

应将两个症状分别记录：
A. 加载状态无法退出或数据请求没有产出；
B. 顶部 / 底部交互同时无效（可能是主线程、输入窗口或覆盖层问题）。
