## 三主题崩溃根因

三个主题已经进入 Compose 预设注册表，但传统 View 的 `colors.xml`、`styles.xml`、数组和 `ThemeUtil` 映射没有同步完成。旧取色路径把 `resources.getIdentifier()` 返回的 `0` 继续传给颜色读取 API，产生 `Resources.NotFoundException`；坏主题 ID 持久化后会在每次冷启动重复触发。
